## 📌 About the Project

**SkyCast** is a weather application designed to make weather information easy to explore and understand. It provides current weather conditions, hourly forecasts, and a multi-day forecast through a clean and responsive dashboard.

Whether you want to check the temperature, explore upcoming weather conditions, or search for a different city, SkyCast brings essential weather information together in one place.

## ✨ Features

- 🌡️ **Current Weather** — View current temperature and weather conditions.
- 🕒 **Hourly Forecast** — Explore upcoming weather conditions throughout the day.
- 📅 **7-Day Forecast** — Check the weather forecast for the coming days.
- 🔍 **City Search** — Search for weather information by city.
- 📍 **Location Support** — Access location-based weather when supported by the application.
- 🌅 **Weather Insights** — Explore weather details and daily conditions.
- 📱 **Responsive Design** — Use the dashboard across desktop, tablet, and mobile screens.
- 🎨 **Modern Interface** — Enjoy a clean layout with weather-focused visuals.

## 🚀 Getting Started

Follow these steps to run SkyCast locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/priyanshu-kumar-dev/SkyCast.git
```

**2. Navigate to the project directory**

```bash
cd SkyCast
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🌐 Weather API

SkyCast uses the [Open-Meteo API](https://open-meteo.com/) to retrieve weather information.

Open-Meteo provides weather forecast data through its API, making it possible to display current conditions and forecast information in the application.

Refer to the official documentation for API details:
https://open-meteo.com/en/docs
